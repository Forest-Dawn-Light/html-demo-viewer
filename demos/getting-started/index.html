👋 Getting Started

Entry Point

Welcome to HTML Demo Viewer — a Vite-based platform for viewing, navigating, and sharing HTML demos with a VitePress-like experience.

How it works

  1. Drop HTML files into the demos/ folder (any depth).
  2. Run npm run generate:manifest to scan and update the page list.
  3. The viewer automatically discovers and displays every demo in the left sidebar.
  4. Share any page with a direct link: /?page=demos/path/to/file.html

Optional metadata

Place a .meta.json sidecar file next to any HTML file to control its display and ordering: 

{
  "id": "my-demo",
  "label": "My Demo",
  "group": "Examples",
  "order": 1,
  "tags": ["ui", "form"],
  "description": "A sample contact form",
  "entry": false
}
💡 Mark a page with "entry": true in its meta file and the viewer will open it by default when no ?page= is specified.

Available scripts

  • npm run dev — start the development server
  • npm run build — build for production
  • npm run preview — preview the production build
  • npm run generate:manifest — re-scan demos and update the manifest
